# Maniac 🎮

**Maniac** is a multiplayer horror game built with Unity, where a group of survivors tries to escape a terrifying maniac. The gameplay is focused on asymmetrical multiplayer mechanics, strategic teamwork, and immersive horror atmosphere.

![Maniac Banner](https://img.itch.zone/aW1nLzIwMzc3NTIwLnBuZw==/original/3hs2uw.png)

---

## 🎯 Game Concept

- **Genre:** Multiplayer Horror  
- **Players:** 1 Maniac vs. up to 8 Survivors  
- **Objective:**
  - **Survivors** must hide, complete objectives, and kill the Maniac.
  - **Maniac** must hunt down and eliminate all survivors before they eliminate Maniac.

---

## ⚙️ Features

- 🎮 Asymmetrical multiplayer gameplay.
- 💀 Unique abilities for the maniac and survivors.
- 🧍 Smooth first-person movement and camera controls.
- 🖥️ Built with **Unity 2022.3.53f1**.
- 🌐 Multiplayer powered by **Photon Engine**.
- 💨 Atmospheric horror experience with real-time lighting and post-processing effects.

## 🚀 How to Run

1. Clone the repository:
   git clone https://github.com/vindiem/Maniac.git
2. Open the project in Unity `2022.3.53f1` or newer.
3. Set up Photon:
   - Go to `Window > Photon > Photon Unity Networking > Setup Wizard`
   - Enter your App ID from the Photon Dashboard (https://dashboard.photonengine.com/)
4. Open a scene `PreMenu` and press ▶️ to test.
